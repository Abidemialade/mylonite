# Rehearsal

This directory holds the script that times and records a first-time user's
path through the published [journey docs](../../docs/journey/index.md) —
install, choose a model, point it at a server, find a weakness — on a
clean install of the package, not a development checkout.

## Where `journey.sh` comes from

`journey.sh` is not written by hand. It is generated by a fresh agent that
holds only the pages under `docs/journey/`, with no other context about
how the product is actually built. The generated script is committed
verbatim — the same commands, in the same order, with the same flags the
docs show a reader typing.

Running it this way turns the docs themselves into the test. **Any place
where the generated script's behaviour diverges from what the docs
promise — a flag that doesn't exist, an output path that moved, a step
that needs something the docs never mention — is a docs bug to fix, not a
workflow bug to route around.** One caveat is worth stating plainly: the
agent that generates the script may already know public facts about the
project from its training data, so a clean run is not on its own proof
that a reader with zero prior exposure would succeed just as easily.

## What `rehearsal.yml` runs

The workflow (`.github/workflows/rehearsal.yml`, manual dispatch only)
installs the checked-out package the way the quickstart docs install a
release, then runs `journey.sh` once per cell in a fresh scratch git
repository created in the runner's temp directory — never in the checkout
itself, so a step in the script that commits or opens a branch never
touches this repository.

**Matrix:** operating system x example server x model provider —

- **Operating systems:** Linux, Windows.
- **Example servers:** the bundled memory server, the kitchen-sink
  reference app.
- **Providers:** Anthropic, OpenAI, a small local Ollama model.

Two cell shapes are dropped rather than run for free: every Windows +
Ollama cell (Windows-hosted runners can't host the service container this
workflow uses for Ollama on Linux), and Windows + the kitchen-sink server
against a hosted provider (not a budgeted cell — see below). Every Ollama
cell, and both dropped shapes, cost nothing.

## Budget

Every Mylonite process in a hosted cell (Anthropic or OpenAI) is capped
at `max_llm_calls` requests (hard cap 150), exported as
`MYLONITE_MAX_LLM_REQUESTS` so the ceiling holds whatever flags the
generated script passes. A cell runs several spending commands, so its
worst case is `max_llm_calls` times the number of spending commands in
`journey.sh`. Size each dispatch from that product. A dispatch with the
matching provider key unset skips that cell with a notice instead of
failing the run.

## Output

Each cell uploads its console log, any `reh_timing.csv` the script wrote,
and Mylonite's own output directory as one artifact, named for its
operating system, server and provider.
