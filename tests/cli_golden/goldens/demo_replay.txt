Each finding becomes a committed regression test, validated against this same vulnerable/guarded oracle. Turn one into

Make a target file (no API key):
mylonite scan --command python --arg app.py --scaffold app.yaml --scope my-app
Scan it (needs an API key):
mylonite scan --target-file app.yaml --authorize my-app
