
 Usage: mylonite report [OPTIONS] TARGET

 Render a saved scan or validation as a trust panel (offline, no LLM).

 A clean, screenshot-able "why you can trust this" readout. For a validation it
 shows the verdict, the gating formula with
 live per-leg marks, the fires/resists reproducibility counts, the per-seed
 kill matrix, and the compliance tags. For a scan it shows the findings,
 coverage (incl. any NOT TESTED gap), and compliance tags. Exit 2 if no
 loadable artefact is found.

┌─ Arguments ─────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ *    target      PATH  A scan dir, a generated/validated dir, or a scan_report.json / validation_report.json.       │
│                        Renders the trust panel for whichever it finds.                                              │
│                        [required]                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
┌─ Options ───────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ --sarif        PATH  Also write a SARIF 2.1.0 file for GitHub code scanning (the Security tab + PR checks). Each    │
│                      result carries severity, compliance tags, and the differential proof (fired N/N, resisted      │
│                      M/M). Takes a PATH.                                                                            │
│ --json         PATH  Also write a machine-readable JSON finding bundle (severity, compliance, localization,         │
│                      differential proof, proven control) for dashboards / SIEM / bots. Takes a PATH.                │
│ --help               Show this message and exit.                                                                    │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘

 Examples:
 `mylonite report .mylonite/scans/<dir>` -- terminal trust panel (offline, no LLM).
 `mylonite report <dir> --sarif out.sarif` -- GitHub code scanning (Security tab + PR checks).
 `mylonite report <dir> --json finding.json` -- machine-readable bundle (dashboards/SIEM/bots).
