**Weakness class: indirect prompt injection (W2).** Untrusted content (a note
body, retrieved document, tool result) reached the model and was followed as an
instruction. Wrap all retrieved/tool content in an explicit untrusted-data
envelope, instruct the model that envelope contents are never commands, and
prefer structured extraction over free-form "read and act". The guarded
reference twin wraps note bodies in `<untrusted>...</untrusted>`.
