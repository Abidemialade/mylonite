# Allowlist for scripts/check_no_hardcoded_models.py.
#
# One entry per line: <path> | <matched text or a stable regex> | <count> | <reason>
#
# Blank lines and lines starting with "#" are ignored. The path is relative
# to the repo root. `count` is how many times the pattern is expected to
# match somewhere in that file TODAY -- not which line. Matching is by
# content, not location, on purpose: a line-number-keyed allowlist breaks on
# any unrelated edit above the flagged line, which would make an
# unconnected change fail a required check. See the script's module
# docstring for the full reasoning.
#
# The check fails when a file holds a matched occurrence no entry's pattern
# covers at all, when a covered pattern matches MORE than its count, or when
# an entry's pattern no longer matches anything in its file (stale).
#
# This list may only shrink (both the number of rows and the sum of their
# counts are pinned as ceilings in tests/test_check_no_hardcoded_models.py).
# If you remove a hardcoded model or credential read, lower the matching
# count (or delete the row) and lower the ceiling in the same PR. If you add
# a new one, you almost certainly want mylonite.scan.providers /
# require_llm() instead; if there is a genuine reason it can't go through
# the registry, add a row here with that reason and raise the ceiling in the
# same PR, and say so in the PR description.

# mylonite/providers/registry.py is exempt BY PATH (see _REGISTRY_PATH in
# scripts/check_no_hardcoded_models.py) -- it's the one module allowed to
# name a provider's model prefix or credential env var(s) by design, and
# allowlisting its rows one by one here would just restate its own typed
# fields.
